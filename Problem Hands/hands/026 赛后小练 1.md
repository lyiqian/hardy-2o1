- 在你方开叫并得到示强应叫后,敌方如果争叫或阻击,则你的 Pass 可以是逼叫性的,
它要求同伴必须叫牌,不可以 Pass。这在竞叫、尤其是高阶竞叫中越来越频繁,在有经验的牌手中尤其是这样。
- Pass 可以将同伴的技术性加倍转化为惩罚性的,此时的 Pass 相当于惩罚性加倍,与
此相类似的应用是,某些再加倍之后的 Pass,也具有认可、示强、转而惩罚敌方的含义。

1. **逼叫性Pass**：

逼叫性 Pass 是竞争中,尤其是满贯叫牌中最有利的武器之一,也是最易引起同伴间
混乱的约定叫。

一般来说,逼叫性 Pass 应用在这样一种局势：

同伴双方有了配合并且已明确要继续叫牌的意图(邀局或试探满贯)，这时你右方的牌手插叫了，你的 Pass 就是逼叫性的，它表示这样一种牌情或意愿：
不愿意防守对方定约，但自己又没有独自叫高一级的实力或没有合适的叫品，希望同伴进一步叫牌。如果没有合适牌型或没有额外实力就加倍。
最普通的情况就是你方叫到了局，对方做出牺牲叫，你用逼叫性 Pass 向同伴表达有额外实力，希望同伴继续叫牌的意图。

记住逼叫性 Pass 应用的重要条件就是:“在没有加倍就 Pass 对方的定约肯定是不对的”。

一个逼叫性 Pass 是邀请同伴进一步叫牌，所以也是显示做庄牌力的潜在价值。
通常在敌方花色中无废，邀请同伴有牌型或额外牌力时就继续叫牌，当然,这不是命令性的，而是建议性的。只要你认为你们没有继续叫牌的实力时就加倍，建议同伴停叫，即使他在敌方花色是单张，低限时也是如此。只要你们认为你们完不成高一阶定约,你就在于要用逼叫性 Pass 来鼓励同伴叫牌。
一个例外的例子,就是当你的牌有极强的作庄能力、极弱的防守能力时,你不能对对
方的定约加倍，可以先 Pass，同伴争到高一级定约你当然高兴；同伴加倍,你就要立即改叫到高一级定约,相信同伴一定会明白你的苦心的。
